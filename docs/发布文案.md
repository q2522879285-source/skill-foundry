## 短版（社群 / VX / 即刻）

我做了一个工具，专门体检 Agent Skills 的**触发问题**。

起因很实在：技能越装越多，但「该用的时候没被调用」这件事，你根本没法知道 ——
它不报错，只是静默失效。

**Skill 出厂台**，五个能力：

· **试一条** —— 打一句你平时真会说的话，立刻看会被哪些技能接住，跑多次还能看出稳不稳
· **路由体检** —— 批量对账成六类结论：稳定命中 / 摇摆 / 漏触 / 误触 / 正确不触发 / 观察
· **关系图谱** —— 谁引用了谁、哪些重复、谁没人用
· **打包发布** —— 13 项检查（含「有没有把 API Key 写进文件」），过闸才给打包
· **静态体检** —— 不花模型，随时能跑

**严格只读你的技能库** —— 它给改法建议，但一个字都不动你的 skill 文件。

MIT 开源，WorkRally MCP App 也能命令行跑：

github.com/q2522879285-source/skill-foundry

## 长版（技术社区 / 博客）

### 技能写好了，但你知道它真的会被调用吗？

Agent Skills 生态里有个很隐蔽的问题：**「装了不生效」**。

它的四种形态：

| 形态 | 表现 | 你原来怎么发现 |
|---|---|---|
| 漏触 | 该用某技能，模型没用 | 只能靠感觉，说不清 |
| 误触 | 不该用，模型硬套 | 以为技能质量差 |
| 抢触发 | 两个技能都被命中 | 越装越乱，找不到罪魁 |
| 死触发 | 触发词根本没人那样说 | 静默失效，作者永远不知道 |

根因其实很直白：技能的 `description` 是**给模型路由器看的接口**。
但从来没有人测过这个接口 —— 我们写完就直接扔进去用了。

**Skill 出厂台** 就是来补这一环的。

### 五个能力

**① 试一条（摸底）**

把你真会说的话打进去：

```
「做一个这两个角色打斗的视频，30 秒」
  ● 动作编排参考    [图像与视频]   3/3 次
  ◐ 专业分镜导演    [分镜与镜头]   2/3 次（摇摆）
```

跑 3 次能看出它是**稳定触发**还是**时灵时不灵**。不判对错，先摸清现状。

**② 路由体检（验触发）**

攒几条真实说法当语料，整体跑一遍，对账成六类结论，最后**归因到具体线索词**：

> 有两个技能共用「动作」，职责又相近 → 建议把线索词各收窄一半，或直接合并

**③ 关系图谱（看结构）**

124 个技能、704 条引用，全画出来就是一团毛线球。所以做成三层渐进：

- 全景：域当一个点，只看域间依赖
- 下钻：点进去看域内技能和外部依赖
- 聚焦：点一个技能，只看它的连线

**④ 打包发布（出门）**

13 项检查分三档，**阻塞项不过就不给打包**：

> ⚠ 有 1 个阻塞问题，先处理再打包：
> · 疑似把密钥写进了文件：在 config.txt 里发现疑似 API Key

实测在我自己的库上跑出：**`ppt-master` 有 12903 个文件、75 MB** ——
没这个闸门，我就把它发到市场去了。

**⑤ 静态体检（零成本）**

线索词冲突、描述高度重复、哪些技能从没被测过。不花模型，随时能跑。

### 几个设计决定

**严格只读。** 它只给可粘贴的改法建议，**绝不修改任何 skill 文件**。
你的技能库是资产，工具没资格动它。

**跨领域通用。** 分类表不是影视专用 —— 14 个能力域覆盖开发、数据、内容、设计、运营…… 换个写代码的库来扫也能正常归类。

**模型可选。** 平台自带 / OpenAI 兼容（DeepSeek、Moonshot、本地 Ollama）/ Anthropic 都行。
**不接模型也能用** —— 静态体检和关系图谱全是本地计算。

**中文名。** 技能 id 大多是英文 slug（`action-choreography-reference`），
中文用户看不出是什么。工具会给中文名，词表覆盖不了的交模型翻一次，结果缓存复用。

### 怎么跑

```bash
npm install && npm run build

# 静态体检（先跑这个，不花模型）
node ./node_modules/tsx/dist/cli.mjs mcp-server/cli.ts static

# 试一条
node ./node_modules/tsx/dist/cli.mjs mcp-server/cli.ts probe "帮我做个 30 秒的打斗视频"
```

也能内置进 Codex：设置页点一下，之后在 Codex 里说「帮我体检技能库」就能用。
